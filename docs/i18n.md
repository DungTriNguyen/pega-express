# Đa ngôn ngữ (next-intl)

- `vi` mặc định ở `/`, `en` ở `/en` (`localePrefix: "as-needed"`). Không tự đổi ngôn ngữ theo trình duyệt.
- Slug được dịch: `src/i18n/routing.ts` → `pathnames` (vd. `/bang-gia` ↔ `/en/pricing`). Slug động (tuyến, dịch vụ, chính sách) lấy từ dữ liệu `{ slug: { vi, en } }`.
- Nút đổi ngôn ngữ giữ đúng trang tương ứng, kể cả trang động (bảng slug tương ứng được layout dựng từ repository).
- `hreflang` vi/en/x-default + canonical do `buildMetadata()` sinh cho mọi trang.

## Thêm chuỗi

Thêm khóa vào **cả** `src/i18n/messages/vi.json` và `en.json` (cùng cấu trúc). Dùng `useTranslations("ns")` (client) hoặc `getTranslations("ns")` (server). Không viết chuỗi hiển thị trong JSX.

## Quy ước slug

Tiếng Việt không dấu, theo ý định tìm kiếm: `/gui-hang-di-uc`, `/chuyen-phat-hoa-toc-noi-dia`. Tiếng Anh: `/ship-to-australia`, `/domestic-express`.

## Thêm ngôn ngữ (ko, ja, zh…)

1. Thêm mã vào `routing.locales` và bản dịch slug cho mọi pathname.
2. Tạo `src/i18n/messages/<lang>.json`.
3. Mở rộng `localizedSchema` trong `src/domain/schemas.ts` và dữ liệu `{ vi, en, <lang> }`.
4. Không sửa component.

CRM (GĐ4) chỉ tiếng Việt.
